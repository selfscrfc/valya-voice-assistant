# Гибридное распознавание и энергопотребление

Vosk small-ru постоянно распознаёт только активацию и границы реплики. После «чат» в памяти собирается запись поручения, включая двухсекундный буфер перед активацией. Текст поручения формирует локальный Whisper large-v3-turbo через MLX. Модель загружается и прогревается один раз; пока пользователь не обращается к ассистенту, Whisper не выполняет распознавание.

Распознавание идёт в отдельном потоке. Во время обработки новой реплики ассистент не принимает следующую голосовую команду; письменный ввод остаётся доступным. Смена микрофона, тайм-аут и озвучка сбрасывают незавершённый захват. Поздний результат от прежнего микрофона не выполняется. Whisper повторно проверяет наличие слова «чат» в начале записи: без него поручение отклоняется. Пропуски активации самим Vosk эта замена не исправляет.

## Установка и переключение

```sh
cd ~/wchat
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/download_whisper.py
./desktop --asr hybrid
```

Гибридный режим включён по умолчанию. Загрузка весов составляет около 1,6 ГБ. После установки распознавание работает локально без сетевого API. Файлы модели: `~/Library/Application Support/wchat/models/whisper-large-v3-turbo/`. Перед переключением режима завершите работающее приложение. Для сравнения с прежней схемой:

```sh
~/wchat/desktop --asr vosk
```

## Что логируется

При каждом запуске автоматически начинается запись в `~/Library/Application Support/wchat/metrics/YYYY-MM-DD.jsonl`:

- раз в 60 секунд: процент батареи, напряжение, ток, оценка мощности разряда всего Mac, CPU и RSS дерева процессов приложения;
- при прогреве: его длительность;
- при обращении: активация, длительность записи, начало и длительность Whisper, ошибки и отклонённые результаты.

Аудио и текст реплик не сохраняются в этих логах. Файлы доступны только владельцу. CPU 100% соответствует одному полностью занятому ядру. RSS может повторно учитывать общие страницы процессов. CPU завершившихся между отсчётами дочерних процессов может быть недоучтён. Логи разделены по дням и накапливаются, их можно архивировать или удалить вручную. При одном отсчёте в минуту объём составляет порядка мегабайта в сутки, в зависимости от числа команд.

Сводка за последние сутки:

```sh
~/wchat/.venv/bin/python ~/wchat/scripts/energy_log.py --report
```

За неделю: добавьте `--hours 168`. Интервал регулируется `--energy-interval 60`, минимальное значение 10 секунд. `--no-energy-log` отключает сбор. Частые опросы сами добавляют нагрузку, поэтому для повседневного использования оставлен интервал в минуту.

## Как сравнивать расход

Мощность разряда, рассчитанная как ток умножить на напряжение, относится ко всему компьютеру. Это не мощность приложения. На зарядке значение отсутствует. Мгновенные показания батареи шумные; для сравнения нужны повторные окна одинаковой длительности, примерно 15-30 минут, с неизменными яркостью экрана, периферией и фоновыми приложениями.

1. Завершите ассистента. Запишите фоновый расход:

```sh
~/wchat/.venv/bin/python ~/wchat/scripts/energy_log.py --label app-off --duration 900
```

2. Запустите `~/wchat/desktop --asr vosk`, оставьте без команд на такое же время.
3. Перезапустите с `~/wchat/desktop --asr hybrid`, дождитесь готовности микрофона и оставьте на такое же время. Первые отсчёты загрузки и прогрева не относятся к установившемуся расходу.
4. Повторите гибридное окно с одинаковым набором поручений, затем сравните сводку. Не используйте длительность скачивания модели как оценку фонового потребления.

Дополнительная средняя мощность распознавания приблизительно равна энергии одного распознавания, умноженной на количество обращений в час и делённой на 3600. Например, условные 20 Вт в течение 2 секунд при 30 обращениях в час дают 0,33 Вт в среднем. Это пример расчёта, а не измерение этой реализации. Для батареи с доступными 60 Вт·ч каждый дополнительный 1 Вт означает около 1,7 процентного пункта заряда в час; фактическая ёмкость зависит от состояния батареи.

## Подробные замеры CPU/GPU

`powermetrics` требует прав администратора. Команда для десятиминутного окна с секундным интервалом:

```sh
sudo /usr/bin/powermetrics --samplers cpu_power,gpu_power --sample-rate 1000 --sample-count 600 --output-file ~/Downloads/wchat-powermetrics.txt
```

Пароль вводится в терминале. Выходной файл: `~/Downloads/wchat-powermetrics.txt`. Значения CPU/GPU тоже относятся ко всей системе и являются оценкой Apple. Для атрибуции нужны сравнимые окна с выключенным ассистентом, Vosk и гибридным режимом. Лог приложения позволяет сопоставить всплески с прогревом и распознаванием.

## Короткая проверка 2026-11-19

Mac: M4 Pro, 24 ГБ. Два установившихся десятисекундных отсчёта внутри короткого окна ожидания по 35 секунд на режим; это проверка работоспособности измерений, а не достаточный батарейный бенчмарк.

| Режим аудиопроцесса | CPU, % одного ядра | RSS |
| --- | --- | --- |
| Vosk | 4,08-6,96 | 238-239 МБ |
| Vosk + прогретый Whisper | 6,96-7,95 | 1983-1993 МБ |

На синтетической непрерывной команде буфер длиной 3,8 секунды распознан за 0,485 секунды. На команде с паузой после активации буфер 5,2 секунды распознан за 0,551 секунды. Обычная речь без активации не запускала Whisper. Запись с завершающим «звук» прошла весь путь до настоящего Codex и локальной озвучки. Это не оценка точности на естественной речи пользователя.

Фоновые приложения не фиксировались, часть функциональных проверок шла одновременно с короткими окнами. Поэтому разница мощности разряда Mac между этими окнами не приписывается ассистенту. Часовой расход и эффект на автономность ещё нужно измерить по методике выше. Подробный `powermetrics` не запускался: для него требуется пароль администратора.
