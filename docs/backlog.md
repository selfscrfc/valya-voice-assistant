# Бэклог wchat

## Озвучка краткого ответа по команде «звук»

Статус: запланировано, не реализовано.

Если пользователь завершает поручение отдельным словом «звук», ассистент выполняет поручение, составляет короткий ответ и озвучивает его. Например: «Посмотри, что изменилось в проекте, звук».

Ожидаемое поведение:

- Последнее слово «звук» является переключателем озвучки для одной реплики; регистр и завершающая пунктуация не влияют на распознавание.
- Переключатель удаляется из текста поручения перед отправкой исполнителю. Правило применяется к голосовому и письменному вводу.
- После выполнения формируется краткий ответ для прослушивания, ориентировочно 1-3 предложения: результат, существенная ошибка или необходимое уточнение. Полный ответ остаётся в чате; краткая версия также отображается текстом.
- Без завершающего слова «звук» ответ остаётся текстовым. Упоминание этого слова в середине поручения не включает озвучку.
- Озвучку можно прервать. Собственный голос ассистента не должен запускать новую команду через микрофон.

Проверка при реализации: команды с переключателем и без него, регистр и пунктуация, слово в середине фразы, успешное выполнение и ошибка, остановка воспроизведения и отсутствие повторной активации от озвучки.

Речевой движок и голос выбрать при реализации; предпочтение локальной озвучке без отдельного API-ключа.
