# wchat

Личный голосовой ассистент для macOS: DJI Mic Mini -> кодовое слово «чат» -> локальное распознавание просьбы -> задача в сессии Codex -> ответ в системном оверлее и письменном чате.

Статус: разведка и проектирование. Исполняемого приложения пока нет.

## Что строим

- Постоянное локальное ожидание кодового слова «чат» с явным индикатором микрофона и кнопкой паузы.
- Голосовые поручения и письменный чат с общей историей.
- Выполнение задач через Codex с авторизацией ChatGPT по подписке, без отдельного API-ключа.
- Продолжение выбранной сессии, отмена задачи, потоковый ответ и восстановление истории.
- Системный оверлей поверх окон, меню в строке macOS и горячая клавиша.
- Низкая задержка: лёгкое ожидание активации, прогретое распознавание, постоянно работающий процесс Codex и показ первых фрагментов ответа.

Локальными будут приложение, аудиозахват, распознавание и хранение истории. Codex выполняет модельные запросы в облаке: это гибридная архитектура, а не полностью автономный офлайн-ассистент.
