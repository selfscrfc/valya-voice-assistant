# wchat

Личный голосовой ассистент для macOS: DJI Mic Mini -> кодовое слово «чат» -> локальное распознавание просьбы -> задача в сессии Codex -> ответ в системном оверлее и письменном чате.

Статус на 2026-11-18: работают отдельное окно чата для macOS и терминальный клиент: постоянный голосовой ввод, локальное распознавание, сессии Codex и общий контекст проектов. Оверлей поверх других окон и озвучка пока не реализованы.

## Запуск

Нужны macOS, Python 3.14 и установленный Codex CLI с входом через ChatGPT. Проверенные версии CLI: 0.169.0 и 0.170.0. Для сборки окна нужны Xcode Command Line Tools (`swiftc`) и macOS 14+. Аудио распознаётся локально; в Codex передаются текст принятого поручения и сохранённый общий контекст. Отдельный API-ключ не используется.

```sh
cd ~/wchat
make setup
./run --devices
./run --device "DJI"
```

`make setup` устанавливает зависимости в `.venv` и загружает небольшую русскую модель Vosk в `~/Library/Application Support/wchat/models/`. `./run` без параметров также ищет единственный микрофон с DJI в имени. Если его нет или найдено несколько устройств, клиент сообщает об ошибке. Другой микрофон выбирается явно через `--device ID` из списка.

Для встроенного микрофона Mac: `./run --device "MacBook Pro Microphone"`. Флаг `--text` полностью отключает микрофон: в этом режиме произнесённые фразы не распознаются. При запуске выводится отдельное сообщение `voice_disabled`. Для голосового режима дождитесь `voice_ready` с именем выбранного микрофона.

После сообщения `voice_ready` говорите: «Чат, сколько будет два плюс два?» Кнопки не нужны. Допускается небольшая пауза после «чат». Слово должно стоять в начале распознанной реплики; «мы обсуждали чат» не является активацией. Если за 12 секунд не появляется новое распознаваемое содержание, захват поручения сбрасывается. Незавершённое поручение длиннее 60 секунд также сбрасывается.

Во время выполнения микрофон продолжает слушать. Каждое новое поручение начинается с «чат» и ставится в очередь. «Чат, стоп» запрашивает отмену выполняемой задачи; очередь можно очистить командой `/clear`. Для остановки приложения и освобождения микрофона используйте `/quit` или Ctrl+C.

При запуске `./run` терминал должен оставаться открытым. Окно `./desktop` работает самостоятельно. В обоих случаях Mac должен бодрствовать; автозапуск и оверлей пока не реализованы.

## Окно чата

```sh
cd ~/wchat
./desktop --device "MacBook Pro Microphone"
```

Первый запуск собирает `~/wchat/build/Wchat.app`. Затем приложение можно открывать из Finder; явно выбранный через `--device` микрофон запоминается. Для DJI: `./desktop --device DJI`. Без сохранённого выбора клиент ищет DJI, как терминальная версия. Параметры запуска применяются при новом запуске процесса, поэтому перед сменой микрофона завершите приложение. `./desktop --text` запускает письменный чат без микрофона. Одновременно использовать `./run` и окно с одним хранилищем нельзя.

В окне есть отдельные сообщения пользователя и ассистента, потоковые ответы, жирный текст, ссылки, выделенные блоки кода, копирование ответа, список диалогов, очередь и остановка. Enter отправляет, Shift+Enter добавляет строку. Технические события не выводятся в переписку. Диагностика процесса хранится в `~/Library/Application Support/wchat/desktop.log`, stderr Codex - в `~/Library/Application Support/wchat/codex.log`. Закрытие окна завершает клиент и освобождает микрофон.

Кнопка **«Общий контекст»** внизу слева открывает поле для путей к файлам, описаний проектов и общих пояснений. Текст сохраняется в локальной SQLite и добавляется при запуске каждого поручения во всех диалогах, включая голосовые. Сами файлы автоматически не загружаются. Изменение применяется к ещё не запущенным поручениям; предыдущие сообщения остаются в истории Codex. При необходимости полностью нового контекста создайте новый диалог.

Там же задаётся папка для новых диалогов. Существующие диалоги сохраняют свою рабочую папку. По просьбе пользователя текущий локальный `default` переведён в `~/Documents/jack` с сохранением его thread и истории.

Разрешения Codex и MCP показываются отдельными карточками и требуют явного ответа. Простые формы используют поля и списки; сложные схемы - JSON с проверкой. Статусы показывают очередь, выполнение, остановку и ошибку. Фактический результат действия указан в самом ответе; завершение ответа модели не считается подтверждением действия.

## Сессии и письменный чат

По умолчанию создаётся постоянный диалог `default` в `~/Documents/jack`. Папка должна существовать; изменить значение для новых диалогов можно в окне общего контекста. Его контекст сохраняется после перезапуска. Именованные диалоги имеют отдельные threads Codex и рабочие папки. Последний выбранный диалог восстанавливается при запуске. `--cwd` задаёт папку только при создании нового диалога и не меняет существующий.

```sh
./run --text
./run --session backend --cwd ~/backend-modules --text
./run --once 'Кратко опиши текущую задачу' --session backend
```

В терминале можно печатать поручения одновременно с голосовым вводом:

| Команда | Действие |
| --- | --- |
| `/sessions` | Показать диалоги и активный |
| `/new ИМЯ [ПАПКА]` | Создать отдельный диалог и выбрать его; без папки использовать папку текущего |
| `/use ИМЯ` | Переключиться в существующий диалог |
| `/history` | Показать последние 20 поручений и ответов текущего диалога |
| `/queue` | Показать последние ожидающие/выполняемые задачи и задачи с неизвестным исходом |
| `/cancel` | Отменить текущую задачу, включая стадию запуска |
| `/clear` | Отменить ожидающие задачи, не прерывая текущую |
| `/approve ID yes` или `/approve ID no` | Ответить на показанный запрос разрешения Codex |
| `/answer ID ВОПРОС ОТВЕТ` | Ответить на вопрос агента; для нескольких вопросов ответить на каждый |
| `/elicit ID accept\|decline\|cancel [JSON]` | Ответить на запрос MCP; объект JSON передаётся одним аргументом в одинарных кавычках |
| `/quit` | Остановить клиент и микрофон |

Пути с пробелами заключаются в кавычки. Адресат голосового поручения фиксируется при распознавании «чат», письменного - при отправке. Переключение диалога не перенаправляет очередь. Пока исполняется одна задача за раз во всём клиенте.

История хранится в `~/Library/Application Support/wchat/history.sqlite`, диагностический лог Codex - в `~/Library/Application Support/wchat/codex.log`. Исходное аудио не сохраняется. Codex также ведёт собственную историю. После аварии неизвестные исходы и неотправленные задачи помечаются для проверки и не повторяются автоматически. Второй клиент с тем же хранилищем не запускается.

Запросы разрешений подтверждаются карточками в окне чата или командами в терминале; голосовое подтверждение пока отсутствует. В режимах `--once`, `--wav` и без терминального ввода запросы разрешений отклоняются. После обрыва Codex клиент останавливает исполнение очереди и требует перезапуска. Песочница Codex: запись в рабочую папку, разрешения по запросу.

## Проверки

```sh
make test
./run --wav tests/fixtures/command.wav --transcribe-only
./run --wav tests/fixtures/command.wav --cwd /tmp
```

Последняя команда выполняет реальный запрос через подписку. `--transcribe-only` проверяет активацию и транскрипцию без отправки в Codex. `--json` включает машиночитаемые события. Аудиофикстуры синтетические; `make test` не обращается к облачной модели.

Проверены реальный текстовый запрос, продолжение thread после перезапуска, выполнение файловой задачи с сохранностью существующего файла, отмена, новый диалог и полный путь синтетического аудио до ответа Codex. Захват встроенного микрофона открывается и корректно останавливается. DJI, качество естественной речи, длительное ожидание, энергопотребление и поведение при сне ещё не проверены. Подробности: [результаты проверки](docs/validation.md).

## Что остаётся

- Проверить DJI, бытовой фон и ложные активации короткого слова «чат».
- Улучшить распознавание свободных поручений и измерить задержку/батарею. Первый прототип использует Vosk для всей речи, не только для ключевого слова; Whisper ещё не подключён.
- Добавить озвучку по «звук», оверлей, строку меню, паузу микрофона без выхода и горячие клавиши.
- Проверить восстановление микрофона после сна и переподключения, добавить фоновый автозапуск.

Приложение, аудиозахват, распознавание и собственная история локальны. Codex выполняет модельные запросы в облаке: это гибридная архитектура.
